# Thử nghiệm tham chiếu bằng mã nguồn

`ket-qua.json` ghi các run đã khóa, kiểm tra hash code, kết quả theo vai trò,
citation, tài nguyên và quyết định giữ `classic-v1` làm mặc định.

Chi tiết: [báo cáo tiếng Việt](../../../docs/reports/danh-gia-tham-chieu-bang-ma-nguon.md).
Không coi dữ liệu phát triển/tự tạo là đánh giá độc lập. Không sửa log/nhãn
để cải thiện chỉ số. Các mã đoạn được tạo từ nguồn, không phải nhãn tấn công.
